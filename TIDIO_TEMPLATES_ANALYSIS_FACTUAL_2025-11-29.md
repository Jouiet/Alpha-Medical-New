```yaml

1.8 Click: "Use this template" button

Success Criteria: Template editor opens with pre-configured flow
```

**STEP 2: Configure Trigger (3 minutes)**
```yaml

2.3 Click: "Advanced settings" dropdown

2.6 Set: Device = All (desktop + mobile)

2.8 Click: "Save trigger"
```


## RISKS & MITIGATION

### Risk 1: Chat Overload (Too Many Proactive Messages)

**Risk Description:**
- Multiple flows trigger simultaneously (e.g., Welcome Message + Lead Gen Bot + Cart Booster)
- Visitor annoyed by excessive popups
- Result: Negative brand perception

**Mitigation:**
```yaml
Solution 1: Flow Priority Rules
  - Set maximum 1 proactive message per session
  - Priority order: Cart Booster > Lead Gen Bot > Welcome Message
  - Implementation: Tidio settings → Flow Priority

Solution 2: Timing Delays
  - Welcome Message: 5 seconds after page load
  - Lead Gen Bot: 60 seconds OR 50% scroll (whichever first)
  - Cart Booster: 30 seconds on cart page
  - Result: Staggered triggers (avoid overlap)

Solution 3: A/B Testing
  - Test 1: Single flow per session vs multiple flows
  - Metric: Bounce rate, engagement rate
  - Decision: Use data to optimize flow frequency
```

### Risk 2: Brand Voice Misalignment

**Risk Description:**
- Tidio templates use casual/playful tone
- Alpha Medical = medical context (professional tone required)
- Result: Trust reduction

**Mitigation:**
```yaml
Solution: Custom Messaging (All Templates)
  - Replace default template copy with medical-appropriate language
  - Avoid: Emojis, slang, overly casual tone
  - Use: Professional, empathetic, informative language

  Example (Cart Booster):
    ❌ Template default: "Hey! Don't miss out! 🎉 Get 10% off now!"
    ✅ Alpha Medical: "Complete your order today and save 5% on medical-grade equipment."

  Example (Welcome Message):
    ❌ Template default: "Hey there! 👋 What brings you here today?"
    ✅ Alpha Medical: "Welcome to Alpha Medical. How can we help you find the right pain relief solution?"
```

### Risk 3: Lead Magnet Quality (Phase 2)

**Risk Description:**
- Lead magnets (PDFs) are low quality OR generic
- Visitors download but don't engage
- Result: Low email list quality (high unsubscribe rate)

**Mitigation:**
```yaml
Solution 1: Professional Content Creation
  - Hire medical writer OR healthcare professional review
  - Include: Clinical studies, expert quotes, actionable tips
  - Format: Professional design (Canva template OR Fiverr designer)

Solution 2: Value Validation
  - Test lead magnets with 5-10 target customers (feedback survey)
  - Metric: "Would you recommend this guide? Yes/No"
  - Threshold: 80%+ "Yes" required before launch

Solution 3: Continuous Improvement
  - Track: Download rate, email engagement post-download
  - Update: Refresh content quarterly based on customer questions
```

### Risk 4: Shopify Event Integration Failure

**Risk Description:**
- Shopify Events (7 automatic events) fail to trigger Tidio flows
- Result: Flows don't execute, automation broken

**Mitigation:**
```yaml
Solution 1: Pre-Launch Testing
  - Test EACH Shopify Event manually:
    1. Create test account → Trigger "User registered" event
    2. Fill email form → Trigger "Filled email form" event
    3. Visit contact page → Trigger "Contact page visited" event
    etc.
  - Verify: Tidio flow executes correctly for each event

Solution 2: Monitoring & Alerts
  - Enable: Tidio analytics email reports (weekly)
  - Monitor: Flow trigger count (should be >0 if traffic exists)
  - Alert: If flow trigger = 0 for 7 days → investigate

Solution 3: Fallback Plan
  - If Shopify Events fail: Use Tidio's behavior-based triggers instead
  - Example: "User registered" event fails → Use "Time on site 2 min" trigger
```
