## UGC SCRIPT FRAMEWORK

### Structure Universelle (Hook → Problem → Solution → CTA)

**FRAMEWORK COMPLET (6 Steps):**

```
1. HOOK (2-3 secondes) ⚡
   └─ Arrêter le scroll: auditory, visual, ou text-based

2. PROBLEM (3-5 secondes) 😟
   └─ Relatable struggle: "If you're like me and..."

3. SOLUTION (5-7 secondes) ✨
   └─ Organic transition: "Luckily, I discovered..."

4. VALUE PROPS (5-7 secondes) 🎯
   └─ 2-3 differentiators (time, quality, price, results)

5. SOCIAL PROOF (3-5 secondes) ⭐
   └─ Implied endorsements, stats, viral validation

6. CTA (2-3 secondes) 🔥
   └─ Urgency: "Get yours before they sell out AGAIN!"
```

**DURÉE TOTALE:** 15-30 secondes (optimal: 20 secondes = 60 mots)

---

### Hook Types (3 Categories)

#### 1. AUDITORY HOOKS
- Sound effects
- Trending songs
- Voice tone shifts
- "You'll never believe what just came in the mail..."

#### 2. VISUAL HOOKS
- Before/After transformations
- Product unboxing
- Transitions/emojis
- Real-life action démonstrations

#### 3. WORD-BASED HOOKS (Health/Medical Products)
- **Symptom-based:** "Stop scrolling if brain fog hits" / "If knee pain stops you from..."
- **Time-bound:** "See calmer joints in 7 days"
- **Problem-agitation:** "Struggling with chronic back pain? 🤔"
- **Social proof:** "My friend's mom, who's a physical therapist, couldn't stop raving..."
- **POV format:** "POV: You finally found the solution to..."
- **Authority:** "Stop doing [wrong approach], switch to this instead! 🔥"

---

### Health/Medical Products: Best Practices

#### Messaging Framework
1. **Symptom matching** (4-6% CTR, 2x generic ads)
2. **Single-benefit clarity** (reduce cognitive load)
3. **Proof anchoring** (clinical studies, FDA registered, certifications)
4. **Speed** (3-5 sec decision window)

#### Recommended Formulas
- **PAS:** Problem → Agitation → Solution
- **AIDA:** Attention → Interest → Desire → Action
- **3-Part:** Hook → Proof → How-to

#### Time-Based Testimonials (Très efficace pour health)
- "30 days with this knee brace..."
- "Week 1 vs Week 4 back support results"
- "Before surgery vs 2 weeks post-op with compression therapy"

#### Authority Endorsements
- "My friend's mom, who's a physical therapist..."
- "Used in 500+ PT clinics..."
- "Recommended by orthopedic specialists..."

#### Performance Data
- **10x more clicks** than single image ads (ecommerce)

- **+111% ROAS** catalog carousels vs manual

---

### Format & Specs

**Optimal Configuration:**
- **Format:** 1:1 square (1080x1080px) - best cross-device consistency
- **Cards:** 2-10 cards per ad
- **File size:** <1 MB per image (faster loading = better performance)
- **Visual consistency:** Uniform backgrounds, colors, fonts, angles across all cards

---

### Content Strategy: Card Sequencing

#### Universal Principles
1. **Reward curiosity** - Each card = distinct value (no repetition)
2. **Visual consistency** - Cohesive look & feel across all cards
3. **Decision factors** - Include pricing, logo, certifications, "On Sale" badges
4. **Storytelling** - Unfolding narrative card-by-card

#### Audience-Specific Sequencing

**COLD AUDIENCES (Top Funnel):**
- Lead with social proof + pricing
- Keep product details simple
- Card 1: Hero image + social proof badge
- Card 2-3: 2-3 key benefits (visual + short copy)
- Card 4: Pricing + "On Sale" indicator
- Card 5: CTA + logo

**WARM AUDIENCES (Retargeting - +134% performance):**
- Front-load sales badges + personalized reco
- Include detailed product info
- Card 1: "Welcome back!" + discount badge
- Card 2-3: Previously viewed items or complementary products
- Card 4-5: Detailed features + certifications
- Card 6: Urgency CTA + guarantee

### CAPTIONS (Subtitles) - CRITICAL for 2025

**Why Captions are MANDATORY:**

**Caption Best Practices:**
- **Format:** SRT file upload OR native Meta auto-captions (review/edit required)
- **Timing:** Max 2 lines on screen, 3-4 words per line

- **Style:** White text, black background box (high contrast)
- **Position:** Bottom-center (avoid covering product/face)
- **Font:** Sans-serif, medium-bold weight

#### Example 1: Product-to-Video (Single Product)

```python
import os
import requests
from dotenv import load_dotenv

load_dotenv()

# Configuration
API_ID = os.getenv("CREATIFY_API_ID")
API_KEY = os.getenv("CREATIFY_API_KEY")
BASE_URL = "https://api.creatify.ai/api"

headers = {
    "X-API-ID": API_ID,
    "X-API-KEY": API_KEY,
    "Content-Type": "application/json"
}

def create_product_video(product_url, script=None, avatar_id=None):
    """
    Generate video ad from Shopify product URL

    Args:
        product_url: Alpha Medical Shopify product URL
        script: Optional custom script (auto-generated if None)
        avatar_id: Optional avatar ID (auto-selected if None)

    Returns:
        Video generation job ID
    """
    endpoint = f"{BASE_URL}/product_to_video/"

    payload = {
        "product_url": product_url,
        "video_format": "9:16",  # Vertical for Reels/TikTok
        "duration": 15,  # Seconds
        "include_captions": True  # MANDATORY for mobile
    }

    # Optional parameters
    if script:
        payload["custom_script"] = script
    if avatar_id:
        payload["avatar_id"] = avatar_id

    response = requests.post(endpoint, json=payload, headers=headers)

    if response.status_code == 200:
        data = response.json()
        job_id = data.get("id")
        print(f"✅ Video generation started. Job ID: {job_id}")
        return job_id
    else:
        print(f"❌ Error: {response.status_code}")
        print(response.text)
        return None

# Example usage
product_url = "https://alphamedical.shop/products/tourmaline-magnetic-knee-pads-self-heating-support"
job_id = create_product_video(product_url)
```

def check_video_status(job_id):
    """
    Check rendering status of video

    Args:
        job_id: Job ID from create_product_video()

    Returns:
        Status dict with download URL if ready
    """
    endpoint = f"{BASE_URL}/video_status/{job_id}/"

    response = requests.get(endpoint, headers=headers)

    if response.status_code == 200:
        data = response.json()
        status = data.get("status")  # "pending", "processing", "completed", "failed"

        if status == "completed":
            video_url = data.get("video_url")
            print(f"✅ Video ready! URL: {video_url}")
            return {"status": "completed", "url": video_url}
        elif status == "failed":
            error = data.get("error_message")
            print(f"❌ Video failed: {error}")
            return {"status": "failed", "error": error}
        else:
            print(f"⏳ Status: {status}")
            return {"status": status}
    else:
        print(f"❌ Error checking status: {response.status_code}")
        return None

def download_video(video_url, output_path):
    """Download completed video"""
    response = requests.get(video_url, stream=True)

    with open(output_path, 'wb') as f:
        for chunk in response.iter_content(chunk_size=8192):
            f.write(chunk)

    print(f"✅ Downloaded: {output_path}")

# Check all jobs from batch
def check_batch_status(jobs_file='video_jobs.json'):

    print(f"\n✅ Completed: {len(completed)}/{len(jobs)}")
