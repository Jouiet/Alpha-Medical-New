## 🎯 AD COPY FRAMEWORKS I USE

### Google Ads (Search)
```
Headline 1 (30 chars): [Pain Point] Relief
Headline 2 (30 chars): [Product Type] for [Persona]
Headline 3 (30 chars): [Benefit] + [Trust Element]

Description 1 (90 chars): [Solution] + [Social Proof] + [CTA]
Description 2 (90 chars): [Benefit Details] + [Shipping/Guarantee]

Example:
H1: Knee Pain Relief
H2: Medical-Grade Knee Braces
H3: Trusted by Thousands

D1: Find lasting relief with our professional-grade knee braces. Trusted by thousands. Shop now.
D2: Science-backed support for arthritis, injuries, and everyday comfort. Free shipping + 30-day guarantee.
```

### Facebook/Instagram Ads
```
Primary Text (125 chars):
[Hook] + [Pain Point] + [Solution] + [Social Proof]

Example:
"Struggling with knee pain? Our medical-grade braces provide instant relief. Trusted by 10,000+ customers. Shop now →"

Headline (40 chars):
[Benefit] + [CTA]

Example:
"Relief Starts Here - Shop Braces"

Description (30 chars):
[Trust Element]

Example:
"Trusted by Thousands"
```

### TikTok Ads (Video Scripts)
```
Hook (3 seconds): Problem visualization
Body (12 seconds): Solution demonstration
CTA (3 seconds): Clear action + urgency

Example Script:
[0-3s] "If desk work is killing your posture..."
[3-15s] "This posture corrector changed everything. Designed by physiotherapists, worn by thousands."
[15-18s] "Get yours today - link in bio. Limited stock."
```
