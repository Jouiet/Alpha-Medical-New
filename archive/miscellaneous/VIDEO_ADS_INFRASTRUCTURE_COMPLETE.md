## 🎓 KEY LEARNINGS & NOTES

### Creatify Product Description Limit
- **Field Limit:** ~150 words maximum
- **Template Purpose:** Comprehensive guide (1000 words = script + configuration)
- **What to Copy:** Only [SCRIPT SECTION] from templates (~140-150 words)
- **Everything Else:** Configuration reference (avatar, voice, music, overlays)

### Template Structure Understanding
**Each template contains:**
1. **Script section** (~150 words) → Copy this to Creatify
2. **Avatar selection guide** → Reference when choosing Creatify avatar
3. **Voice selection guide** → Reference when choosing Creatify voice
4. **Captions config** → Reference for Creatify caption settings
5. **Music settings** → Reference for Creatify music selection
6. **Text overlays** → Reference for Creatify text overlay creation
7. **Examples** → See how script looks with actual product
8. **Quality checklist** → Use before rendering

### Asset Organization Best Practices
- **Naming Convention:** `{product-handle}_{type}_{description}.jpg`
- **Minimum Required:** 1 hero + 1 lifestyle (feature optional but recommended)
- **Quality:** Min 1000x1000px resolution, <10 MB file size
- **Verification:** Use `asset_organizer.py --verify` before video creation
