## How to Upload to Klaviyo

### Option 1: Via Klaviyo UI (RECOMMENDED)
1. Go to https://www.klaviyo.com/email-templates
2. Click on the template you want to update
3. Switch to 'HTML' editor mode
4. Copy-paste the HTML from the corresponding file
5. Save the template
6. Repeat for all 10 templates
