**Usage Rules:**

- H1: One per page (Hero/Title)
- Sentence case for headings
- No ALL CAPS for body text

## 3. SPACING & LAYOUT

**Base Unit:** 4px

| Token | Value | PX | Usage |
|-------|-------|----|-------|
| `--space-1` | 0.25rem | 4px | Tight elements |
| `--space-2` | 0.5rem | 8px | Icon spacing |
| `--space-3` | 0.75rem | 12px | List gap |
| `--space-4` | 1rem | 16px | Card padding (sm) |
| `--space-6` | 1.5rem | 24px | Card padding (std) |
| `--space-8` | 2rem | 32px | Section gap (sm) |
| `--space-12` | 3rem | 48px | Section gap (lg) |
| `--container-max` | 1200px | - | Max content width |

**Border Radius:**

- `--radius-sm`: 4px (Buttons/Inputs)
- `--radius-md`: 8px (Cards)
- `--radius-lg`: 16px (Hero/Large Containers)
