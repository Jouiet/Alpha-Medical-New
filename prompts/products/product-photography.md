## 6. NEGATIVE PROMPTS (Always Include)

```
Negative: blurry, low quality, distorted, unrealistic proportions,
watermarks, text overlays, cluttered background, harsh shadows,
overexposed, underexposed, amateur photography, cartoon style,
medical claims text, before/after comparison
```

## Variables to Customize

| Variable | Description | Example |
|----------|-------------|---------|
| `{PRODUCT_TYPE}` | Category of product | knee brace, posture corrector |
| `{MATERIAL}` | Fabric/material description | neoprene, mesh, elastic |
| `{COLOR}` | Primary product color | black, gray, blue |
| `{ACCENT_COLOR}` | Secondary color | copper, blue stitching |
| `{BACKGROUND}` | Background specification | white, gradient, lifestyle |

---

## Quality Standards

- **Resolution:** Minimum 1200×1200px (2400×2400 preferred)
- **Format:** PNG for transparency, JPG for web
- **Aspect Ratio:** 1:1 (square) for Shopify
- **File Size:** Under 500KB optimized
